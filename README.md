Mempelajari penggunaan string dalam Python, meliputi indeks, slicing, metode string, pembersihan teks, pemisahan dan penggabungan kata, pencarian kata, serta normalisasi data mahasiswa.

## 2. Struktur Program

- `latihan/01_dasar_string.py`: operasi dasar string.
- `latihan/02_indeks_slicing.py`: indeks dan slicing.

1. Meminta pengguna memasukkan nama mahasiswa dan kode kelas.
